# 駒画像・巻き戻し・棋譜共有・戦術表示

## 操作

- 駒は `lib/pieces.ts` に同梱した独自SVG画像12種類。盤上、ドラッグ、アニメーション、昇格、ヘッダーで同じ画像を使う。Unicode・フォント・外部CDNには依存しない。
- **巻き戻す**: 練習中は直前の自分の手番へ戻る（通常2 ply、相手の応手待ちや自分の着手で終局した場合は1 ply）。閲覧中は1 ply。再生中は再生を取り消して本譜の局面へ戻る。
- **三回同一局面**: 実戦と解答／失敗手の再生では同じ問題の最初に戻す。履歴・評価・選択・注釈もリセットし、クリア数には加算しない。50手ルールやステイルメイトは従来どおり終局として扱う。読み込んだ棋譜は検討用なので自動リセットしない。
- **FEN**: 現在の盤面・手番・キャスリング権・アンパッサン・半手数・手数を入出力する。過去の着手は含まないので、それ以前の三回同一局面は復元できない。
- **PGN**: 開始局面と本譜の履歴を入出力する。非標準開始局面にはSetUp/FENタグを付ける（chess.jsによる）。コメント・ヘッダーはPGNで保持する。分岐を編集する機能ではなく、本譜を扱う。
- **ファイル入力**: `.fen`、`.pgn`、`.txt` を選択すると内容をテキスト欄に表示する。確認後「読み込む」を押す。不正入力で現在のゲームを変更しない。
- **棋譜URL**: 開始FENとUCI着手列を `#study=` のバージョン付きデータとして持つ。サーバーへの保存は不要。履歴・三回同一局面・昇格を復元する。コメント・対局者名は含まない。
- **盤面URL**: 現在のFENのみを `#fen=` に入れる。URLは現在のホスト・サブディレクトリを維持するためGitHub Pagesと通常配信の両方で利用できる。
- 読込・共有URLを開いた直後は**閲覧モード**。32駒の通常棋譜も閲覧可能で、ネットワーク要求や自動応手をしない。「この盤面を練習」で現在の3〜7駒局面を新たな問題にできる。終局・キャスリング権あり・手番側が負けの局面は練習対象外。
- コピー権限がなくてもテキスト欄から手動コピー可能。100,000文字／ファイル100 KB、棋譜2,048 ply、共有URL16,000文字まで。長い棋譜はPGNファイルで共有する。URLは暗号化ではないため、受け取った人には局面と着手が見える。

## 自動矢印

独立したSVGレイヤーで手動注釈と分離する。ON/OFF設定は `endgame-show-tactics` として端末に保存する。盤面の反転・昇格・再生・巻き戻しでも、表示中の局面から再計算する。

- 赤: チェック／チェックメイト。
- 青: ステイルメイト。キングはチェックされていないため、王への攻撃線は表示せず、逃げ道を覆う利きとマーカーを示す。
- 黄: フォーク（複数の相手の駒への利き）。自分のキングを露出させる絶対ピンの攻撃は除く。
- 紫点線: 直前の着手によって、同じマスのビショップ／ルーク／クイーンから既存の相手の駒への射線が開いたディスカバードアタック。アンパッサンによる開線も対象。

これは探索エンジンではなく、現在の利きの可視化。駒の価値・反撃・交換手順を読んだ駒得の保証や、将来のメイト予告ではない。メイト／ステイルメイトはchess.jsの合法手生成による終局判定。逃げ道の射線はキングの移動元と捕獲される駒を取り除いて計算する。

## 開発・検証

既存のNode 22.13以上とlockfileを利用し、実行時依存は追加しない。

```sh
npm ci
npm test
npx tsc --noEmit
npm run lint
npm run build:pages
npm run build
```

自動テストは `tests/study.test.ts` と `tests/pieces.test.ts` に追加。白／黒の巻き戻し、応手待ち、昇格4種類、アンパッサン、キャスリング権、三回同一局面、PGNとURLの往復、不正入力、フォーク・絶対ピン・開線・メイト・ステイルメイトを扱う。

ブラウザで確認する項目:

1. Windows・macOS・iOS・Androidで6種×白黒の表示。ドラッグ／昇格／アニメーションも同じ画像か。
2. 通信を遅くした状態で巻き戻し／最初から／新規生成／FEN入力を行い、遅れて届いた応手で巻き戻した盤面が書き換わらないか。
3. 最善手再生の一時停止・終了・三回同一局面、手動注釈と自動矢印の独立性、反転した盤面の矢印。
4. 共有URLを新しいタブで開き、通信なしでも元の履歴を再現するか。コピー権限拒否時の代替、スマートフォンのファイル入出力。

実装時の検証環境では外部ホストの名前解決に失敗し、npm依存を取得できなかった。実施済みはTypeScript/TSXの構文変換検査とSVG画像テスト。chess.js依存のテスト、完全な型検査、lint、ビルド、ブラウザ実機テストの成功は未確認。
